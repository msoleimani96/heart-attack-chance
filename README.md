# Heart Attack Chance Prediction
This is a classification project about predicting the chance of a heart attack using the SVM algorithm.
The main challenge of this project was choosing the right factors for training a precise model, and I did it with some research (Domain Knowledge).
Finally, I could make the model 86% accurate.

## How to start?
1. Create a virtual environment:
   `python3 -m venv virtual_environment_name`
2. Activate virtual environment:
   `source virtual_environment_name/bin/activate`
4. Install requirements:
   `pip install requirements.txt`
4. Start jupyter notebook:
   `python -m notebook`
